03 / REVIEW PROTOCOL

How to assess a portfolio result.

01

Reproduce

Open the original repository README and use its actual setup and validation steps. Do not assume a published demo is a deployable service.

02

Check denominators

Read the sample population, data status, split strategy and metric definition. Ask what was excluded or held out.

03

Look for failure

Read poor results, unsupported-answer behavior and forecast uncertainty as carefully as dashboard success measures.
