The first successful end-to-end GitHub Actions QA run on **28 October 2026** ([run #40643160914](https://github.com/harshakavali81-collab/harshavardhan-portfolio/actions/runs/40643160914)) recorded:

- **13/13 live HTML pages returned HTTP 200** in the original tested scope.
- **104/104 Chromium, Firefox and WebKit layout/interaction checks passed** across desktop, tablet and mobile-width profiles.
- **44 external URLs reachable; 0 confirmed broken; 1 HTTP 999 LinkedIn anti-automation response**. The latter is reported as unverified through HTTP automation, not fabricated as an accessible 200. LinkedIn is separately discoverable in public search.
- **All seven critical URLs passed a sub-3000ms p75 navigation load-event target** in both the unthrottled GitHub-hosted desktop environment and a Chromium mobile profile simulating 120ms latency, 1.6Mbps downstream and 4× CPU slowdown.

## Quality and performance

Run `python3 scripts/audit_site.py` locally. The GitHub Actions **Portfolio quality checks** workflow verifies all internal links/assets, fragment references, duplicate HTML IDs, image alt attributes, and required case-study sections. GitHub Pages is served from `main` at the repository root.

- **Mobile:** shared case study/contact styles use responsive CSS breakpoints; mobile appearance needs real device/browser QA.
- **Loading:** static HTML/CSS, no heavy client framework or external tracking. A defined **p75 navigation load-event benchmark** has been measured in GitHub-hosted desktop and simulated mobile-4G Chromium runs; this is **not a universal under-three-second guarantee** across all physical devices or networks.
- **Contact:** the form now opens a pre-filled **Gmail web compose** link directly in Chrome/Edge/Firefox. Visitors need to sign in to Gmail and click Send themselves. A default email-app (`mailto:`) fallback and copy-email button remain available; the static website does not submit messages to a server.
- **External links:** the offline audit checks internal paths only. GitHub, LinkedIn, source media and third-party demo uptime require independent online checking.
- **Privacy:** no hidden analytics, credentials, personal IDs, or applicant tracking are included.
