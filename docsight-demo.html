02 / HOW IT WORKS

Explainable NLP pipeline

1
Validate textUTF-8 TXT, up to 100,000 characters, with an eight-word minimum.
2
Keyword-based category heuristicSix document categories: Invoice, Resume, Contract, Research, Medical and Report. This is not machine learning.
3
Extractive summaryRank sentences without inventing new text; every excerpt is copied from the input.
4
Page-level referencesTXT documents have one source page, so all excerpts cite PAGE 1. Real PDF page references need the full backend.
For real PDF parsing, the synthetic-trained scikit-learn classifier, FastAPI, SQL analytics and Docker, visit the full GitHub project.
