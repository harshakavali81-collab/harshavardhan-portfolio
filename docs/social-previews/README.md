# Repository social previews

Original typographic cards for the 51 project repositories and the GitHub profile repository. These are title cards, not screenshots, measured results or deployment evidence.

Each SVG is editable source. Run `python generate.py` from this directory with Inkscape installed to produce the 1280 × 640 PNG files used in GitHub Settings → General → Social preview.

The black, gold and ivory palette matches the portfolio. Repository names provide the titles; `manifest.json` defines the few shortened display titles. No external photography, logos or datasets are used.
