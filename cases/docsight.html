07 / DOCUMENT INTELLIGENCE · NLP + BACKEND

DocSight AI

Smart Document Classifier & Summarizer — a Python/FastAPI and React prototype that links extractive document summaries to their original PDF pages.

Source code ↗More case studies ↗

Original schematic, not a screenshot of a deployed public service.

01 / PROBLEM

Explainable PDF analysis

Challenge

Document categories and summaries are difficult to verify when the source page is not disclosed.

Objective

Classify documents and return exact excerpted sentences with their original physical PDF page numbers.

02 / PROCESS

From ingestion to evidence

Python ML pipeline

Validates uploads, extracts page-numbered text using PyMuPDF, normalizes it and classifies with TF-IDF plus Logistic Regression. Six categories are trained using 72 synthetic examples.

Application and observability

A verbatim sentence ranker returns page-cited summaries. FastAPI serves JSON; React provides upload, export and live metadata-count charts. SQLite does not store source document content.

03 / RESULTS & LIMITATIONS

What can be verified

The public repository includes a runnable API and UI, pytest checks, reproducible synthetic held-out evaluation, Docker, CI, source and model documentation, and ten original SVG diagrams. A synthetic trained classifier is not a validated real-world model. There is no OCR, public production hosting, authentication or security certification.

04 / TAKEAWAYS

Citations improve traceability, not truth

Page references identify the source of each selected excerpt. Independent data validation, secured deployment and user testing would be needed for trustworthy real-world use.
