01 / SELECTED WORK · Full-stack AI / NLP

Multilingual Indian Language Knowledge Base

A document-centered question-answering workspace for English, Hindi, Telugu, Tamil and Kannada.

Inspect source repository ↗Back to selected work ↗

Design & workflow

Upload or create document → store and index → identify query language → retrieve candidate passages → extract or generate grounded response → return source references and mode.

01 / Problem

Documents and queries can appear in multiple languages, making keyword-only discovery unreliable.

02 / Project objective

Provide searchable documents, language-aware questions, source references, and a traceable answer path.

03 / Technology stack

React + Vite, FastAPI, SQLite (local), optional PostgreSQL/Docker, optional LaBSE sentence embeddings and Groq LLM.

04 / Main features

  • Text/Markdown/text-based PDF ingestion and document management
  • Optional multilingual embeddings with deterministic offline fallback
  • Source-linked answers, question history, analytics and export
  • FastAPI Swagger endpoints and React UI

05 / Verification and testing

Repository documents backend pytest tests, frontend lint/build, and Docker Compose validation. Individual external runtime states and a public deployment were not verified in this update.

06 / Limits and security scope

Hashing fallback is not equivalent to LaBSE, scanned PDFs need OCR, optional model/API resources require configuration, and production hosting/TLS/account operations require separate verification.

07 / What I would improve

Create a representative English/Hindi/Telugu evaluation dataset, report retrieval relevance, failure cases and multi-user security.
