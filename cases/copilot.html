04 / SELECTED WORK · Applied AI / human-in-the-loop support

Multimodal AI Customer Support Copilot

A synthetic-data customer-support copilot that assembles relevant policy evidence and prepares agent-reviewed drafts.

Inspect source repository ↗Back to selected work ↗

Design & workflow

Text/PDF/screenshot/audio request → extraction/transcription → policy retrieval → cited draft → agent review and approval/escalation → local ticket record.

Problem
System design
Implementation
Review & limitations

01 / Problem

Support staff must read policies and customer context quickly while avoiding unsupported responses.

02 / Project objective

Enable evidence-backed drafts for a human agent while retaining manual approval and escalation.

03 / Technology stack

Python web application, TF-IDF baseline, optional Whisper speech transcription, optional neural retrieval, SQLite tickets and optional local LLM configuration.

04 / Main features

  • Policy evidence and source citations for replies
  • Text and PDF extraction, screenshot OCR and optional speech
  • Editable drafts, agent approval and escalation
  • SQLite ticket storage and evaluation scripts

05 / Verification and testing

README reports 20 unit/API tests, 10 synthetic retrieval cases and local smoke validation for optional models. These are repository-reported, not independently verified public service results.

06 / Limits and security scope

No live hosting or real customer records; approval does not send messages. Model downloads, OCR, transcription and deployment security need configuration and validation.

07 / What I would improve

Add authenticated agent accounts, stronger file isolation, public hosting smoke checks and independently reviewed response-quality benchmarks.

08 / Reproduce and inspect

Default mode uses evidence extraction; generation is optional rather than silently assumed.
