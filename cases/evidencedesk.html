02 / The problem

The real challenge behind the screen.

A generated answer without visible evidence is difficult to trust. Document ingestion must also manage PDF pages, text chunks, citation boundaries, absent answers and potentially sensitive uploads.

Project workflow — authored summary
PDF / DOCX / TXT→Extract & chunk→TF-IDF / optional MiniLM→Retrieve sources→Cited answer UI

03 / Process & actions

How the system came together.

01

Ingest and label sources

Extract PDF, DOCX and TXT text and attach page/paragraph/section metadata.

02

Chunk text without losing tails

Use overlapping windows, source bookkeeping and duplicate handling.

03

Build a tested offline baseline

Use TF-IDF vectors and cosine retrieval to return cited excerpts without an external LLM.

04

Make richer modes optional

Implement MiniLM dense embeddings and opt-in Groq drafting as extra configurations, not assumed tested outputs.

05

Measure and disclose limits

Run authored retrieval/abstention fixture questions, 16 pytest checks and a CLI persistence smoke test.

06 / Key takeaways

What mattered, and what comes next.

  • Showing source excerpts supports user verification better than unsupported free-form answers.
  • Tests should cover negative/unsupported questions, not just obvious successes.
  • Next steps: independent corpora, live semantic/LLM validation, privacy review and multi-user security.
