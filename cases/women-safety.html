Women Safety Device — GPS & GSM

A fingerprint-activated device concept integrating location information and mobile communication for safety alerts.

Inspect source repository ↗Back to selected work ↗

Design & workflow

Finger access → controller decision → GPS location acquisition → GSM message or alert sequence → local buzzer/LCD indications, as described in project materials.

01 / Problem

In emergencies, a discreet way to initiate a location-aware notification can assist users, if implemented and tested reliably.

02 / Project objective

Document the design of an Arduino-based system integrating fingerprint input, GPS, GSM and alert components.

03 / Technology stack

Arduino UNO, fingerprint sensing, GPS, GSM, buzzer, LCD, LEDs and power supply (as documented in the repository).

04 / Main features

  • Fingerprint activation concept and device block diagram
  • GPS and GSM integration plan
  • Buzzer, LCD and LED indicators
  • Academic report and presentation material

05 / Verification and testing

Repository README documents the design and supporting reports. No independent real-device safety certification, field reliability testing or successful emergency transmission was established here.

06 / Limits and security scope

This is an educational hardware project, not an approved emergency response device. Coverage, battery life, GPS availability, communication delay and user consent would require real tests.

07 / What I would improve

Publish non-sensitive wiring photographs, firmware revision, controlled test logs, GPS error measures, alert delay and failure handling.

08 / Reproduce and inspect

Only claim functions actually shown in the repository materials. No public live demo is asserted.
